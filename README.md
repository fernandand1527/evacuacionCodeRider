## ✨ Acerca del Proyecto

**Evacuación Coderider** es una plataforma web desarrollada con **Django** que centraliza la respuesta ante emergencias. Permite registrar reportes detallados en tiempo real, adjuntar evidencias multimedia (imágenes, documentos, audios) y administrar de forma fluida los recursos esenciales de seguridad.

---

## 🚀 Características Principales

| Módulo | Descripción |
| :--- | :--- |
| 📝 **Reportes en Vivo** | Formulario dinámico para registrar incidencias de evacuación con archivos adjuntos. |
| 📂 **Gestión Documental** | Soporte para almacenamiento y descarga de PDFs, ZIPs, CSVs y rutas GPS. |
| 🔊 **Multimedia Integrada** | Reproducción de alertas de audio y visualización de recursos interactivos. |
| 🛡️ **Panel Administrativo** | Control total de registros y usuarios mediante el ORM de Django. |

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python / Django 
* **Frontend:** HTML5 / CSS3 / Plantillas nativas de Django
* **Geolocalización:** Leaflet.js
* **Control de Versiones:** Git y GitHub
* **Base de Datos:** SQLite
